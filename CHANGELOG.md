# Журнал змін (Changelog)

Усі помітні зміни в проєкті документуються в цьому файлі.
Формат ведеться за стандартом [Keep a Changelog](https://keepachangelog.com/) та відповідає [Semantic Versioning](https://semver.org/).

## [1.3.7] — 2026-10-21
### Fixed
- **Пріоритет номера відділення над номером будинку (Strict Warehouse Number Parsing):**
  - Додано строгий парсинг цільового номера відділення (`/(?:відділення|відд|склад|№|#)\s*(\d+)/i` або число в кінці запиту).
  - Точний збіг `branch.number` із цільовим числом отримує вирішальний пріоритет (`+5000` балів), щоб номер будинку на схожій вулиці ніколи не перебивав шукане відділення (наприклад, `"Городок 1"` гарантовано видає першим Відділення №1).
- **Ізоляція населеного пункту (Контекст міста > Вулиці інших сіл):**
  - При 100% збігу назви населеного пункту (Exact Match) заблоковано підтягування відділень з інших сіл лише через збіг по вулиці та номеру будинку (`"Борщів Чортківський Бандери 1"` повертає суто м. Борщів без домішування с. Садки).
- **Маппінг укрупнених районів КАТОТТГ (Нові райони 2020 ↔ стара база НП):**
  - Додано таблицю відповідності `KATOTTG_RAION_MAP` та функцію `areRaionsCompatible` для двостороннього зіставлення нових і старих районів (`Фастівський` ↔ `Києво-Святошинський`/`Макарівський`/`Васильківський`, `Бучанський`, `Чортківський`, `Тернопільський` тощо).
  - Запит `"Тарасівка Фастівський"` безпомилково знаходить с. Тарасівка, навіть якщо в базі район вказано як Києво-Святошинський.

## [1.3.6] — 2026-10-21
### Fixed
- **Каскадний нечіткий пошук (Cascading Fuzzy Fallback):**
  - Реалізовано двоступеневий каскад у `searchBranches` та `getAutocompleteSuggestions`: Крок 1 (суворий точний збіг за всіма токенами) та Крок 2 (Relaxed/Fuzzy Fallback за префіксами, морфологічними коренями та аліасами міст на кшталт `"днепр"` ➔ `"Дніпро"`, `"кв"` ➔ `"Київ"`, `"льв наук"` ➔ `"Львів, вул. Наукова"`).
  - Виключено порожні екрани «не знайдено», коли в базі присутні близькі за змістом міста чи відділення.
- **Очищення сміттєвих символів із чатів (Chat Syntax Sanitizer):**
  - Додано функцію `sanitizeChatQuery`, яка м'яко вичищає лапки всіх видів (`« »`, `" "`, `' '`), дужки, слеші, знаки номерів (`№`, `#`) та повторювані символи пунктуації (`---`, `===`), дозволяючи безпомилково розпізнавати запити з месенджерів (наприклад, `"«Київ» № 22"`, `"«м. Одеса» № 5"`, `"Львів-Наукова (склад)"`).
- **Надійність випадаючих підказок (Dropdown / Autocomplete Behavior):**
  - Забезпечено стабільне відкриття підказок при введенні 1–2 літер (`"ки"`, `"од"`, `"дн"`, `"хм"`).
  - При виборі будь-якого варіанта зі списку (клік мишкою, тач або Enter) випадаючий список миттєво ховається (`classList.add('hidden')` + `display: none`) зі скасуванням усіх незавершених debounce-таймерів, не залипаючи поверх картки відділення чи інтерактивної карти.

## [1.3.5] — 2026-10-21
### Fixed
- **Усунення сітки «API KEY REQUIRED» (Tile Layer Fix):**
  - Замінено тайловий шар карти на стабільні публічні тайли OpenStreetMap (`tile.openstreetmap.org`) для світлої теми та CartoDB Dark Matter (`basemaps.cartocdn.com/dark_all`) для темної без обмежень чи вимоги API-ключа.
  - Карта бездоганно відмальовує реальні вулиці та міста України без водяних знаків та сіток.
- **Ліквідація стрибків екрана (Zero Layout Jump / Jerky Scroll):**
  - Заблоковано будь-які зміщення скролу (`window.scrollTo`) та стрибки фокусу при кліку на маркер чи відкритті поп-апу.
  - Зафіксовано висоту контейнера карти (`.map-card` та `.leaflet-map-canvas`), завдяки чому поява картки відділення не виштовхує карту вгору.
  - Додано параметри `autoPan: false` та `autoPanPadding: L.point(10, 10)` для відкриття балуна в Leaflet, запобігаючи різким зміщенням карти.
- **Логіка скасування вибору (Кнопка «✕ Скинути вибір» / Reset Selection):**
  - Додано кнопку «✕ Скинути вибір» у шапку блоку та кнопку-хрестик на саму картку відділення.
  - По кліку скидається стан вибору, прибирається картка, знімається підсвітка та активний статус маркера з карти.
  - Якщо активний таб фільтра порожній (наприклад, поштомати у населеному пункті, де є лише звичайні відділення), інтерфейс автоматично скидає фільтр на «Всі» без блокування видачі.

## [1.3.4] — 2026-10-21
### Added
- **Двосторонній фокус та синхронізація списку й карти (Hover Sync & Instant Select):**
  - При наведенні курсору (`mouseenter`) на будь-який рядок у списку результатів чи підказку автокомпліту відповідний маркер на карті плавно збільшується (масштаб 1.36×) та підсвічується яскравим неоновим сяйвом (червоним для Нової пошти, жовтим для Укрпошти).
  - При кліку на маркер на карті не лише відкривається балун, а й миттєво активується вибір відділення (`renderSelectedBranch`): під картою відкривається повна картка з кнопками «📋 Скопіювати» та «📋 Детально».
- **Покращений UX спливаючого вікна над маркером (Marker Pop-up UX):**
  - Додано великий помітний бейдж вагових обмежень та габаритів («🚛 Вантажне: до 1100 кг (600×220×220 см)», «📮 Поштомат: до 20 кг», «🏬 До 30 кг» або «📮 Індекс: ...»).
  - Компактний заголовок із номером відділення та адресою без необхідності вертикального скролу.
  - Робоча кнопка «📋 Скопіювати» безпосередньо в балуні з миттєвим копіюванням у CRM через `fallbackCopy` та візуальним таймером підтвердження «✓ Скопійовано!» на 1.5 секунди.
- **Адаптивна картографічна підкладка (Light / Dark Theme Tiles):**
  - Динамічна заміна тайлових шарів картки: високодеталізовані світлі тайли CartoDB Positron / Voyager для світлої теми та CartoDB Dark Matter для темної теми.
  - Плавне оновлення тайлового шару при зміні теми без перезавантаження сторінки та зі збереженням усіх відображених маркерів.
  - Початкове завантаження відповідного шару тайлів на основі збереженої в `localStorage` теми.

## [1.3.3] — 2026-10-21
### Added
- Динамічне підвантаження карти за видимою областю (BBox) та рівнем зуму: при відкритті карти без пошукового запиту автоматично відображаються маркери у видимих межах України.
- Ієрархія відображення за масштабом: при низькому зумі (`zoom < 11`) виводяться вузлові хаби та вантажні відділення (до 45 точок), а при наближенні (`zoom >= 12`) — усі локальні відділення (до 60 точок одночасно з Canvas-рендером).
- Панель швидких фільтрів над картою: перемикач «[ Всі ] | [ 🚛 Вантажні (>30 кг) ] | [ 🏬 Відділення (до 30 кг) ] | [ 📮 Поштомати ]» з автоматичним приховуванням непідтримуваних типів для Укрпошти.
### Fixed
- Надійний fallback копіювання: автоматичний обхід помилок `navigator.clipboard` (Permissions/Unfocused у iframe CRM) через тимчасовий `textarea` та `document.execCommand('copy')`.
- Повна підтримка копіювання як для карток Нової пошти, так і для Укрпошти.
### Removed
- Повністю видалено сторонні кнопки «Маршрут» / «Прокласти маршрут» із карток та спливаючих вікон карти для фокусування оператора на внесенні даних.
