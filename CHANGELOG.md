# Журнал змін (Changelog)

Усі помітні зміни в проєкті документуються в цьому файлі.
Формат ведеться за стандартом [Keep a Changelog](https://keepachangelog.com/) та відповідає [Semantic Versioning](https://semver.org/).

## [1.3.2] — 2026-10-21
### Fixed
- Усунення білого екрана Leaflet: гарантований виклик `window.leafMap.invalidateSize()` через 150мс після відкриття карти та явне закріплення розмірів контейнера (`height: 100%`, `min-height: 400px`).
- Суворі географічні межі карти: закріплення перегляду виключно межами України (`ukraineBounds`: 44.0°–52.5° N, 22.0°–40.5° E, `maxBoundsViscosity: 1.0`, `minZoom: 6`, `maxZoom: 18`).
- Оптимізація пам'яті та рендерингу маркерів: увімкнено Canvas-рендер (`preferCanvas: true`), обмежено кількість маркерів до 20 точок активної видачі/поточного міста; ліквідовано критичне зависання через спробу одночасного рендерингу 55k DOM-елементів.
- Миттєва чутливість кнопки закриття: подвійне прив'язування listener до кнопки та секції карти (`#btnCloseMap`), очищення шарів маркерів та звільнення пам'яті при закритті.

## [1.3.1] — 2026-10-21
### Fixed
- Сувора типізація вантажних пунктів: статус «Вантажне відділення» надається виключно точкам із лімітом ваги >= 1000 кг або категорією Cargo (виправлено 8 075 сільських відділень та кейс Обухова).
- Захист від перезапису номера: номер відділення/поштомату береться суворо з бази даних і не підміняється цифровими токенами з пошукового запиту.
- М'яка нормалізація пунктуації: токенізатор коректно вичищає коми, слеші, крапки в скороченнях («м.», «с.», «смт.») без збою парсера ("м. Київ, 222", "Львів / Наукова").
- Резервний буфер обміну (Clipboard Fallback): обхід обмежень Clipboard API в iframe CRM-систем через document.execCommand('copy') та усунення залипання бейджа копіювання.
### Security & Quality
- Успішне проходження повного сьюту регресійних автотестів (36/36) у tests/test_autocomplete.js.

## [1.3.0] — 2026-10-20
### Added
- Пряма кнопка «💬 Фідбек» у верхній навігаційній панелі з відкриттям офіційної Google Форми у новій вкладці (target="_blank") без ризику втрати введених у пошук даних.
- Адаптивність хедера: автоматичне згортання кнопки до компактної іконки 💬 на екранах <= 640px.
### Changed
- Оновлення Service Worker з миттєвою активацією (skipWaiting та clients.claim) для гарантованого оновлення ресурсів без ручного очищення кешу.

## [1.2.0] — 2026-10-20
### Changed
- Глобальне очищення головного екрана: пом'якшено фоновий контраст активної служби, видалено зайву кнопку «Обрати ➔», кнопка «Шукати» центрована без іконок.
- Ізоляція історії пошуку: сховище останніх запитів суворо розділено окремо для Нової пошти та Укрпошти.
- Повнопулова фільтрація табів: панель («Всі», «Вантажні», «Відділення», «Поштомати») не зникає при 0 результатів та фільтрує по всьому пулу точок міста.
### Removed
- Видалено тимчасову кнопку розробника «📦 Поштомат» над полем вводу.
- Видалено дублюючі плашки поштових індексів у підвалі картки Укрпошти.

## [1.1.0] — 2026-10-20
### Added
- Дворівневий UX випадаючого списку (City Mode ↔ Branch Mode) у стилі LP-CRM: вибір населеного пункту з гео-дужками та миттєвий перехід до відділень при введенні цифри або назви вулиці.
- Ергономічний дворядковий стиль підказок: рядок 1 — номер, іконка, вага; рядок 2 — вулиця, будинок, орієнтир.
### Fixed
- Ліквідовано паразитну підсвітку (over-highlighting): службові слова («вул.», «буд.», «відділення») більше не фарбуються жовтим маркером; вичищено артефакти переносу рядків "\n".

## [1.0.0] — 2026-10-19
### Added
- Офіційний реліз рушія прогресивного контекстного звуження Delengine.
- Підключення повного реєстру 55 185 відділень, поштоматів та вантажних хабів Нової Пошти з лімітами ваги, габаритами та адресами.
- Подвійна система копіювання: швидка кнопка «📋 Скопіювати» (формат для покупця) та кнопка «📋 Детально» (CRM-формат з областю, районом у дужках та лімітом ваги).
- Підтримка пошуку за назвою вулиці без номера відділення ("городок рівненська штейн").
### Fixed
- Повна уніфікація всіх різновидів апострофів (' ʼ ’ `) та складених назв топонімів ("Великий Дальник", "П'ятихатки").

## [0.8.0] — 2026-10-19
### Added
- Інтеграція вичерпного реєстру 26 588 міст, смт і сіл України через офіційне API Нової Пошти (all_settlements.js).
- Топонімічна ієрархія: пріоритезація діючих сільських пунктів над однойменними райцентрами та вулицями зі швидкістю пошуку O(1).

## [0.5.0] - [0.7.0] — 2026-10-18
### Added
- Scoring Matrix Engine: універсальне математичне ранжування збігів без хардкодних if/else.
- Прямий індексний пошук Укрпошти за 5-значними індексами та адресний класифікатор.
- Підтримка пошуку поштоматів за 4-6 значними номерами по всій країні.
### Changed
- Оптимізація пам'яті (-56% ваги бази), LRU-кеш швидкого відгуку (< 0.01 мс) та пакетний DOM-рендеринг через DocumentFragment.

## [0.1.0] - [0.4.0] — 2026-10-17
### Added
- Первинний робочий прототип (MVP): підтримка базового пошуку відділень НП та індексів Укрпошти.
- Контрастні теми оформлення Calm White та Obsidian Dark зі збереженням у LocalStorage.
- Інтеграція підкладки карти Leaflet та перші шаблони швидкого копіювання для LP-CRM.
