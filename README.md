# 📦 Пошукова система відділень «Нова пошта» та «Укрпошта» (Прототип)

Інтерактивний веб-прототип пошукової системи відділень Нової пошти та Укрпошти, спроєктований точно за наданим вайрфреймом Figma (MacBook Pro 16").

---

## 🚀 Основний функціонал прототипу

1. **Дві поштові служби (Вгорі по центру):**
   - Перемикач між **«Нова пошта — вибрати пошук»** та **«Укрпошта — вибрати пошук»**.
   - Адаптивні теми з фірмовими кольорами (червоний для НП, блакитно-жовтий для Укрпошти).
   - Автоматична зміна контексту пошуку та підказок.

2. **Плашка пошуку та кнопка «Шукати»:**
   - Пошук за назвою міста, номером відділення (наприклад, `1`, `14`, `10520`), вулицею або поштовим індексом (для Укрпошти: `01001`, `79000`).
   - Кнопка швидкого очищення поля (`✕`).
   - Картки знайдених відділень з адресою, графіком роботи, телефонами та інформацією про наявність генератора.

3. **Найчастіші запити (Під пошуком):**
   - Сітка з 10 популярних міст (2 рядки по 5 елементів): **Київ, Дніпро, Одеса, Житомир, Запоріжжя, Львів, Харків, Вінниця, Полтава, Миколаїв**.
   - Система аналізу запитів протягом дня: кожен новий або повторюваний запит оновлює лічильник частотності в `localStorage`.
   - Клік на будь-яку плашку миттєво запускає пошук.

4. **Історія останніх пошуків (Нижче найчастіших запитів):**
   - Зберігає останні 5 унікальних запитів за 5 днів.
   - Відображає бейдж служби («НП» або «Укрпошта»), текст запиту та час («Щойно», «15 хв тому», «Вчора»).
   - Клік на запис миттєво повторює пошук.
   - Кнопка «Очистити» для очищення історії.

5. **Інтерактивна карта відділень (Кнопка «Показати карту» над пошуком праворуч):**
   - Побудована на базі безкоштовної та відкритої бібліотеки Leaflet (OpenStreetMap).
   - Кольорові мітки відділень (червоні для НП, сині для Укрпошти) з детальними спливаючими вікнами.
   - Кнопка «Моя геолокація» для пошуку найближчих відділень навколо користувача.
   - Пряме посилання «Прокласти маршрут» у Google Maps.

6. **Нижні кути екрана:**
   - **Лівий нижній кут:** кнопка **«v0.1.0 Історія версій»** — відкриває модальне вікно з журналом змін поточного прототипу та планами на майбутні релізи.
   - **Правий нижній кут:** індикатор **«Онлайн: 34»** з живою зеленою пульсацією та динамічною зміною кількості відвідувачів.

7. **Підтримка API:**
   - Вбудована автономна база відділень для ключових міст України.
   - Вікно налаштувань (іконка шестерні вгорі праворуч) з можливістю ввести власний ключ API Нової пошти.

## 💻 Як запустити проєкт

### Варіант 1: Відкрити напряму в браузері
Просто двічі клікніть або відкрийте файл [index.html](file:///Users/Диск%20Д/06%20Проекти/НП%20+%20УКР%20-%20search%20/index.html) у будь-якому браузері (Chrome, Safari, Edge, Firefox).

### Варіант 2: Локальний веб-сервер через Python
У терміналі виконайте:
```bash
python3 -m http.server 8080
```
Після цього перейдіть за адресою: `http://localhost:8080`
