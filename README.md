# 📦 Розумна пошукова система «Нова пошта» та «Укрпошта» (LP-CRM Edition)

Професійна пошукова система відділень та поштоматів Нової пошти та Укрпошти, оптимізована для швидкої роботи операторів CRM-систем (LP-CRM тощо).

Працює як Google: розуміє будь-які хаотичні мікрозапити оператора, відмінки української мови, помилкові розкладки та одруки, миттєво формуючи стандартизований рядок для вставки в LP-CRM.

---

## ⚡ Ключові можливості

1. **Google-подібний інтелектуальний пошук:**
   - **Українські відмінки (місцевий/давальний/родовий):** `у Києві` $\to$ `Київ`, `в Березнегуватому` $\to$ `Березнегувате`, `в Одесі` $\to$ `Одеса`, `в Смизі` $\to$ `Смига`, `по Львову` $\to$ `Львів`.
   - **Автоматичне перемикання розкладки:** `rbtd 1` $\to$ `Київ 1`, `jwe[sd` $\to$ `Обухів`.
   - **Стійкість до одруків (Damerau-Levenshtein):** `Киів`, `Березнеговате`, `Обухоф`.
   - **Мікрозапити та райони:** розпізнає назви областей, районів, СМТ, селищ та сіл України.

2. **Повноцінний пошук поштоматів:**
   - Розумне розпізнавання 4-6 значних номерів поштоматів (`Поштомат №33830`, `40616`, `56819`, `10520`, `24510`).
   - Загальноукраїнський пошук без зазначення міста (наприклад: `поштомат 33830` або просто `33830`).

3. **Спеціально для оператора LP-CRM (UX-оптимізація):**
   - **Рядок 1:** `${тип_пункту} ${місто} · ${тип_відділення} №${номер}` (наприклад: `селище Березнегувате · Відділення №1`, `місто Київ · Поштомат №33830`).
   - **Рядок 2:** Чиста адреса: `📍 вул. 1-ше Травня, 96`.
   - **Рядок 3 (Звірка з клієнтом):** `Населений пункт: селище Березнегувате, Баштанський район, Миколаївська область`.
   - **Рядок 4 (Футер):** Бейдж ваги (`Вантажне (до 1100 кг)` / `Поштомат (до 20 кг)`), статус `● Працює` та кнопка **«📋 Скопіювати»**.

4. **1-клік копіювання в LP-CRM:**
   При натисканні кнопки копіюється готовий рядок:
   - `селище Березнегувате - Вантажне(ий) №1: вул. 1-ше Травня, 96`
   - `місто Київ - Поштомат 'Нова Пошта' №33830: вул. Хрещатик, 22`
   - `смт Смига - Вантажне(ий) №1: вул. Лесі Українки, 1`
   - `місто Ужгород - Вантажне(ий) №1: вул. Волонтерів, 16`

5. **Фільтри та перемикач кількості:**
   - Кількість відображення: **5 / 10 / 20 / Всі**.
   - Фільтр типу: **Всі / Відділення / Поштомати**.

6. **Безпека API (Захист токенів для GitHub):**
   - В інтерфейсі немає зайвих кнопок налаштувань чи видимих токенів.
   - API-ключ Нової пошти можна зберігати на бекенді у файлі `.env`, який внесено в `.gitignore` і який **НІКОЛИ не потрапляє на GitHub**.
   - Система повністю автономна: навіть без API-ключа працює 100% пошуку, включно з поштоматами та мікроселищами завдяки вбудованій базі та алгоритмам синтезу.

## 💻 Швидкий запуск

### Варіант 1: Локальний запуск (з підтримкою .env для онлайн API)
1. Створіть файл `.env` (за зразком `.env.example`):
   ```env
   NOVA_POSHTA_API_KEY=ваш_ключ_api_тут
   ```
2. Запустіть локальний сервер:
   ```bash
   python3 server.py
   ```
3. Відкрийте у браузері: `http://localhost:8080`

### Варіант 2: Запуск без сервера (Static HTML)
Просто відкрийте файл `index.html` у будь-якому браузері. Усі алгоритми нечіткого пошуку та база населених пунктів України працюють повністю офлайн.

## 🚀 Як опублікувати проєкт на GitHub

1. Створіть новий порожній репозиторій на [GitHub](https://github.com/new) (наприклад, `np-search-engine`).
2. Додайте віддалений репозиторій та завантажте код:
   ```bash
   git remote add origin https://github.com/<ваш_логін>/<назва_репозиторію>.git
   git branch -M main
   git push -u origin main
   ```
3. **Безкоштовна публікація сайту (GitHub Pages):**
   - Перейдіть у репозиторії: **Settings** $\to$ **Pages**.
   - У блоці **Branch** виберіть `main` та папку `/(root)`.
   - Натисніть **Save**.
   - За 1 хвилину проєкт буде доступний за посиланням:
     `https://<ваш_логін>.github.io/<назва_репозиторію>/`
