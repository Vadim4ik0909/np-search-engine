# Skill: Token & Context Budget Guard

## Rules for AI Agent Execution:
1. Жорстке обмеження на читання великих файлів: ЗАБОРОНЕНО читати data/branches.js та інші файли обсягом > 300 рядків цілком у контекст бесіди.
2. Для аналізу бази даних, коду чи перевірки рядків використовуй точкові команди:
   - `node -e "..."`
   - `sed -n 'start,endp'`
   - `grep -n`
3. Приглушення логів тестування: при запуску тестів перенаправляй вивід або фільтруй його (`node tests/test_autocomplete.js > /tmp/test_log.txt 2>&1 || tail -n 25 /tmp/test_log.txt`). У чат виводь лише фінальний статус (наприклад, "27/27 PASS, Exit Code: 0"). Не виводь сотні рядків термінального логу.
4. Стислість звітів: не дублюй користувачу файли цілком. Надавай лише суть проблеми, застосований git diff і результат тестів.
